# 試作を見せて直したい点を集める

試作を人に見せ、「どこをどう変えたいか」を 1 点ずつ受け取り、試作へ反映して見せ直す往復を、人が「これで固める」と言うまで回す。返事は OK／NG ではなく変えたい点である。実装済みの機能を完了条件と照らして確かめるのは `/demo`・`/demo-e2e` であり、本スキルでは行わない。

> **本スキルは対話前提である**。メインセッションで人と往復する。サブエージェントへ委譲しない。対話相手の人がいない（headless）で起動された場合は、試作を見せずに停止して報告する。

## 入力

対象: $ARGUMENTS（試作のディレクトリ、または機能名。機能名なら `docs/features/<機能>/prototype/` を探す。見つからなければ人に所在を聞く）

呼び出し元が `/define-ux` の場合は、試作のディレクトリと媒体（Web・CLI・API・バッチ・ゲームの画面の流れ）を受け取る。単独で呼ばれた場合は、試作のファイル構成から媒体を推定し、人に確かめる。

## 手順

### 1. 試作と指摘一覧を読む

試作のファイルを列挙し、画面・場面の一覧を作る。試作のディレクトリに `feedback.md` があれば読み、未反映の指摘から再開する（無ければ作る）。

### 2. 試作を見せる（媒体ごと）

- **Web**: 入口の HTML を `open`（Linux は `xdg-open`）でブラウザに開き、画面の一覧とリンクのたどり方を会話に示して、人が自分で触るのを待つ。dev server は起動しない。開けない環境では HTML の絶対パスを示して人に開いてもらう。`file://` で開いた HTML では、リンクの遷移と通常の `<script>` は動くが、`<script type="module">` と `fetch` で読む部分は動かない。そうした部分があれば人に伝え、作り直しになる指摘として手順 4 のとおり見送りに記録する
- **CLI**: 試作にある端末のやりとりを、場面ごとにコードブロックで会話に示す
- **API**: 呼び出しの例（正常・エラー・ページング）を、1 呼び出しずつリクエストとレスポンスの組で示す
- **バッチ**: 入力と出力のサンプル・ログ・通知の文面・失敗時に人が見るものを、場面ごとに示す
- **ゲームの画面の流れ**: Web と同じく HTML を開く（HUD の配置・操作の割り当て・1 ループの流れ）

試作のファイルにあるものをそのまま示し、会話で書き直さない。

### 3. 直したい点を受け取り、一覧に記録する

人の指摘を 1 点ずつ受け取り、`feedback.md` の表に 1 行で記録する。人の言葉は要約せず残し、どの画面・場面への指摘かを付ける。指摘の意図が読み取れないときは、反映する前に聞き返す。

```text
| # | 画面・場面 | 指摘（人の言葉） | 反映の内容 | 状態 |
|---|-----------|----------------|-----------|------|
| 1 | ログイン画面 | ... | ... | 未反映 / 反映済み / 見送り |
```

### 4. 試作へ反映して見せ直す

指摘を試作のファイルへ反映し、表の「反映の内容」と「状態」を更新して、変えた画面・場面だけを見せ直す。反映は既存の試作ファイルの編集と、指摘で必要になった画面・場面の追加に限る。媒体を変える・試作を作り直す指摘は反映せず、見送りとして記録し、呼び出し元へ返す。

### 5. 終わり方

人が「これで固める」と言ったら、状態が「未反映」の行が残っていないかを確かめる（残っていれば、反映するか見送るかを人に聞く）。そのうえで次を返す。

```text
## 試作の確認 完了

- 試作: {試作のディレクトリ}
- 指摘一覧: {feedback.md のパス}（反映済み N 件 / 見送り N 件）
- 固まった点: {画面・場面ごとに 1 行}
- 見送った点: {指摘と理由}
```

呼び出し元が `/define-ux` なら、この報告を返して終わる。単独で呼ばれた場合は、次の段として `/define-feature` に試作のディレクトリを渡せることを案内する。人が途中でやめた場合は、`feedback.md` をその時点の状態で残し、再開のしかた（同じ試作を指定して本スキルを呼ぶ）を示して終わる。

## 注意事項

- 本スキルは試作一式を新しく作らない（`/define-ux` の役目）。実装済みのアプリは操作しない
- 試作は本番のデータ・外部サービスに接続しない。外部送信を伴う操作の見本は文面を示すだけにする
